Created the Question4 directory along with any required parent directories.

--------------------------------------------------

2. Command:
cd ~/SGA-2-ASSIGNMENT/Question4

Explanation:
Changed the current working directory to the Question4 folder.

--------------------------------------------------

3. Command:
pwd

Explanation:
Verified that the current working directory was Question4.

--------------------------------------------------

4. Command:
nano system.log

Explanation:
Created and edited a sample log file containing both INFO and ERROR messages.

--------------------------------------------------

5. Command:
cat system.log

Explanation:
Displayed the contents of the log file to verify that the log entries were created successfully.

--------------------------------------------------

6. Command:
tail system.log

Explanation:
Displayed the last few lines of the log file. The tail command is commonly used to inspect recent log entries.

--------------------------------------------------

7. Command:
grep "ERROR" system.log > error_report.txt 2> /dev/null

Explanation:
Filtered only the ERROR messages from the log file and stored them in error_report.txt. Any error messages generated by the command were redirected to /dev/null to suppress unnecessary output.

--------------------------------------------------

8. Command:
cat error_report.txt

Explanation:
Displayed the contents of the report file to verify that only ERROR messages were extracted successfully.

--------------------------------------------------

9. Command:
ls

Explanation:
Listed the files in the current directory to verify that the log file and the generated report file were present.

--------------------------------------------------

Designed Command Pipeline:

tail -f system.log | grep "ERROR" > error_report.txt 2> /dev/null

Explanation:
This pipeline continuously monitors the log file using tail -f. The pipe (|) sends newly added log entries to grep, which filters only ERROR messages. The > operator stores the filtered output in error_report.txt, while 2> /dev/null suppresses unnecessary error messages.
